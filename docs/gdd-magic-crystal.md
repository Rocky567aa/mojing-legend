## 一、游戏概述

**游戏名称**：魔晶传说  
**核心类型**：伪3D 沙盒 + 综合模拟 + 生存（Pseudo-3D Isometric Sandbox Survival）  
**一句话介绍**：在等距视角的魔晶大陆上自由探索、建造基地、开采矿石、炼制魔晶，从一无所有成长为手握传说圣晶的强者  
**核心情感体验**：
- 🌍 在伪3D等距世界自由探索的自由感
- 🏗️ 亲手搭建魔法基地的掌控感
- ⛏️ 一步步走完炼晶流水线的成就感
- 😱 跳过提纯被副作用惩罚的教训感
- 🌈 全服第一颗彩晶诞生时的震撼感

**参考同类游戏**：星露谷物语（等距建造）+ 泰拉瑞亚（探索生存）+ Diablo（等距视角）+ No Man's Sky（资源炼制）

**目标用户**：15–35 岁，喜欢建造、养成、收集类游戏的玩家

## 三、世界设计：魔晶大陆 🗺️

> **世界规模：1.3亿平方米（130 km²）✅（2026-06-25 用户确认）**

### 3.1 世界尺寸参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 总面积 | **1.3亿 m²（130 km²）** | 约 11,400m × 11,400m |
| 单格瓦片大小 | 4m × 4m | 视觉上约 64×32px 等距菱形 |
| 地图网格大小 | **2850 × 2850 格** | 2850² × 16m² ≈ 1.3亿 ✅ |
| 区块大小 | 32 × 32 格（128m × 128m） | 动态加载单位 |
| 总区块数量 | 约 89 × 89 = **7,921 区块** | 全部预生成种子，按需加载 |
| 玩家可见范围 | 7 × 7 区块（约 896m × 896m） | 渲染性能优化 |

> 对比参考：Minecraft 默认出生点范围约 60km²；魔晶传说是它的 **2.2倍**。

### 3.2 六大地貌区域

| 区域 | 面积占比 | 特色矿石 | 环境描述 |
|------|---------|---------|---------|
| 🌿 **中央草原（起始区）** | 30% | 低阶通用矿 | 平坦开阔，适合新手建基地 |
| 🌋 **火焰峡谷** | 15% | 🔴 火玄矿 | 地表熔岩裂缝，火焰精灵出没 |
| 🏔️ **永冻峡湾** | 15% | 🔵 寒冰晶矿 | 冰封山脉，极光夜空 |
| ⛈️ **裂空高地** | 15% | ⚡ 雷纹矿 | 常年雷暴，浮空岛链 |
| 🌑 **幽暗地穴** | 15% | 🌑 暗影矿脉 | 地下迷宫，无自然光，恐惧值系统 |
| 🏛️ **神圣遗迹群** | 10% | ✨ 圣光矿 + 🌈 混沌原石 | 古代遗址，守护机械，最高风险区 |

### 3.3 区块化动态加载系统

```
世界生成策略
├── 全局种子（Seed）：服务器启动时一次性生成，固定世界地形
├── 生物群系分布：Voronoi 算法 → 六大区域自然边界过渡
├── Simplex Noise：地形高低起伏（等距 Z 轴高度差，±3格）
├── 矿石分布：区域密度随机 + 稀有"矿巢"系统
└── 遗迹生成：手工模板 × 程序化位置选取

区块加载策略（性能关键）
├── 玩家中心 7×7 区块（49块）保持加载
├── 移动时滑动窗口：进入新区块 → 加载，离开 → 序列化到 MongoDB
├── 多玩家共用区块：引用计数机制，避免重复加载
└── 区块状态机：UNLOADED → GENERATING → LOADED → DIRTY → SAVING
```

### 3.4 探索进度系统

```
迷雾系统（Fog of War）
├── 未探索：黑色迷雾覆盖
├── 已探索：半透明暗色（可见地形，不见动态物体）
└── 当前可见：玩家周围 25格 全清

探索奖励
├── 首次进入新生物群系 → 解锁区域传说卷轴
├── 探索度 100% → 解锁区域隐藏传送门
└── 全图 100% → 全服称号「魔晶大陆探索者」
```

## 六、核心系统：基地 + 炼晶生产链 🏭

### 6.1 基地等级

| 等级 | 名称 | 可安装机器 | 最高炼晶阶 |
|------|------|-----------|-----------|
| Lv.1 | 新手小屋 | 搅碎机 ×1 | 🔵 灵晶 |
| Lv.2 | 工匠坊 | + 炼金机 ×1 | 🟣 魔晶 |
| Lv.3 | 魔法工坊 | + 提纯槽 ×2 | 🟡 神晶 |
| Lv.4 | 炼晶殿 | + 高级炼金炉 ×1 | 🔴 皇晶 |
| Lv.5 | 圣晶堡垒 | + 混沌熔炉 ×1 | 🌈 圣晶 |

### 6.2 炼晶流水线

```
矿石采集（1.3亿 m² 世界探索）
    ↓
⚙️ 搅碎机：矿石 → 矿粉 + 杂质渣
    ↓
🧪 提纯槽：矿粉 + 净化剂 → 纯净矿粉   ← 跳过有副作用！
    ↓
🔥 炼金机：纯净矿粉 → ✨ 魔晶
```

### 6.3 副作用系统

| 副作用 | 概率 | 效果 | 可修复？ |
|--------|------|------|---------|
| 🟡 轻微污染 | 40% | 数值降低15% | ✅ 净化卷轴 |
| 🟠 中度腐蚀 | 35% | 强化上限永久-5级 | ❌ 不可逆 |
| 🔴 严重扭曲 | 20% | 随机负面被动 | ❌ 只能丢弃 |
| 💀 炼制爆炸 | 5% | 机器损坏 + 材料全损 | 需材料修复 |
